# TV Sitter parent panel

The parent's pages for TV Sitter: what is on, what was watched, and the rules.

**Home Assistant OS and Supervised only.** Apps do not exist on Home Assistant Container or
Core. The integration does, and it is what enforces anything — this panel is an addition to it
and never a replacement.

It requires the [TV Sitter integration](https://github.com/TomaszSyc/tvsitter) and talks to
Home Assistant rather than to your MQTT broker, so the integration stays the only thing
speaking to the televisions.
